KlattPad

Type text and hear Klattara speak it, with every setting it has. Everything runs in your browser; nothing you type is sent anywhere.

F5 plays the selection or all the text, F6 pauses or resumes, F7 stops.

Voice settings:

Each voice's own settings, which you can change; empty means the voice's own (or automatic). Changing voice shows that voice's.

Keys and commands

F5 plays (the selection if there is one, otherwise all the text), F6 pauses and resumes, F7 stops. A change to any setting applies the next time you play.

Text goes straight to the engine, so commands work, as in DECtalk:

  • [:vs], [:vb], [:vg], [:vd], [:vt] change to Steve, Brittany, Gary, David or Taylor.
  • [:speed 300] sets words per minute; [:cv pi 150 hs 110 br 40] customizes the voice.
  • [:phone klattara enable] lets you write sounds in ARPAbet, such as [HH AH0 L OW1], and sing notes: [AA1<400,20>] sings note 20 for 400 ms.

Klattara is open source: github.com/dgomez42/Klattara.
